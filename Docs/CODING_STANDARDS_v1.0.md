# USSP Coding Standards v1.0

## 1. Purpose

This document defines coding rules and development standards
for the US Stock Screener Professional (USSP) project.

---

# 2. General Principles

USSP code must follow:

- readability
- maintainability
- modular architecture
- clear naming
- documented changes
