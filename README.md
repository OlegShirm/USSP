# USSP
# US Stock Screener Professional

## Version

0.1.0-dev

## Description

USSP (US Stock Screener Professional) is an open-source Excel VBA
application for analysis and screening of US stock market companies.

The project is designed for investors who need a structured tool
for searching, analyzing and monitoring US companies.

---

# Main Features

## Stock Screening

The system will analyze US companies using:

- Market Capitalization
- Stock Price
- 52 Week Low
- 52 Week High
- Sector
- Industry
- Company Age
- IPO Date
- IPO Age
- Expected 1 Year Price Target
